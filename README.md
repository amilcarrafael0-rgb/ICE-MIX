# Ice Mix Web

Esta es una página estática para Ice Mix con edición de textos y colores.

## Publicarla en Internet

La forma más sencilla es usar GitHub Pages:

1. Crea un repositorio en GitHub.
2. Sube estos archivos al repositorio.
3. Entra a Settings > Pages.
4. Activa GitHub Pages usando la rama principal y la carpeta raíz.
5. Espera unos minutos y copia la URL pública.

La página funciona sin backend y se puede abrir desde cualquier dispositivo.
